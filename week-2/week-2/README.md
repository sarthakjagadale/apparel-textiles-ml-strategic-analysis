# Yuva Intern – Week 2

## Data Collection Strategy & Data Quality Assessment

### Objective

This week's task focuses on designing a data collection and quality
assessment strategy for Machine Learning applications in the Apparel &
Textiles industry.

## Main Areas

- Public Data Source Identification
- Data Collection Strategy
- Data Extraction Methods
- API and CSV/JSON Collection
- Web Scraping Considerations
- Data Quality Assessment
- Data Cleaning
- Data Validation
- Data Integration
- Data Governance
- Privacy and Ethics
- ML Data Readiness

## Public Data Sources Studied

- India Open Government Data
- Ministry of Textiles
- MoSPI / eSankhyiki
- U.S. Census International Trade
- Google Trends
- Fashion-MNIST
- Hugging Face Fashion Dataset

## Key Recommendation

The recommended data strategy is:

Source Identification
→ Data Collection
→ Raw Data
→ Data Profiling
→ Data Cleaning
→ Quality Validation
→ Data Integration
→ ML-Ready Dataset
