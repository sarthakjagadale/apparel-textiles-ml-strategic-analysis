# Week 3 References

The following publicly available resources were considered while
developing the Week 3 strategy for Feature Engineering and Data
Preprocessing in the Apparel & Textiles domain.

---

## 1. Scikit-learn Documentation

**Topic:** Data preprocessing, feature selection and dimensionality
reduction.

Scikit-learn provides documentation for techniques such as:

- Standardization
- Min-Max scaling
- Robust scaling
- One-Hot Encoding
- Ordinal Encoding
- Feature selection
- Recursive Feature Elimination
- Principal Component Analysis

Website:

https://scikit-learn.org/stable/

---

## 2. Python Pandas Documentation

**Topic:** Data cleaning, transformation and feature engineering.

Pandas is useful for:

- Handling missing values
- Data type conversion
- Grouping
- Aggregation
- Date processing
- Creating new columns
- Detecting duplicates

Website:

https://pandas.pydata.org/docs/

---

## 3. NumPy Documentation

**Topic:** Numerical operations and mathematical transformations.

NumPy supports numerical calculations used during preprocessing and
feature engineering.

Website:

https://numpy.org/doc/

---

## 4. Google Machine Learning Education

**Topic:** Machine Learning concepts, feature engineering and data
preparation.

Google's Machine Learning resources provide educational material about
features, data preparation, model evaluation and common ML concepts.

Website:

https://developers.google.com/machine-learning/

---

## 5. UCI Machine Learning Repository

**Topic:** Public Machine Learning datasets and data preparation
research.

The repository provides datasets that can be used for studying
Machine Learning workflows and preprocessing techniques.

Website:

https://archive.ics.uci.edu/

---

## 6. Fashion-MNIST

**Topic:** Fashion image classification.

Fashion-MNIST is a widely used dataset containing grayscale images of
fashion products. It can be used to understand image preprocessing and
classification workflows.

Dataset:

https://github.com/zalandoresearch/fashion-mnist

---

## 7. TensorFlow Documentation

**Topic:** Machine Learning and image preprocessing.

TensorFlow provides tools and documentation for:

- Image preprocessing
- Image normalization
- Data augmentation
- Deep Learning

Website:

https://www.tensorflow.org/

---

## 8. PyTorch Documentation

**Topic:** Deep Learning and computer vision preprocessing.

PyTorch provides tools for working with image datasets and Deep
Learning workflows.

Website:

https://pytorch.org/docs/

---

## 9. India Open Government Data Platform

**Topic:** Public Indian datasets.

The Government of India's Open Government Data platform provides
datasets that can potentially support economic, industrial, trade and
other analytical applications.

Website:

https://www.data.gov.in/

---

## 10. Ministry of Textiles, Government of India

**Topic:** Apparel and textile industry information.

The Ministry of Textiles provides information and reports related to
India's textile and apparel sector.

Website:

https://texmin.nic.in/

---

# Reference Usage

These resources were used primarily for understanding:

- Data preprocessing
- Missing value handling
- Feature engineering
- Feature selection
- Feature transformation
- Feature scaling
- Categorical encoding
- Dimensionality reduction
- Image preprocessing
- Machine Learning workflows

The resources are intended to provide technical and domain background
for the proposed Week 3 methodology.
