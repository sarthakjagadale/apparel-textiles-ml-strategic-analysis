# Data Preprocessing Strategy

## 1. Introduction

Data preprocessing is the process of preparing raw data before it is
provided to a Machine Learning model.

Raw Apparel & Textiles datasets may contain missing values, duplicate
records, incorrect data types, inconsistent categories and unusual
values.

Proper preprocessing improves data quality and helps Machine Learning
models produce more reliable results.
