# Feature Selection Methods

## 1. Introduction

Feature selection is the process of identifying the most useful
features from a dataset and removing features that are irrelevant,
redundant or unnecessary.

In Machine Learning, having too many features can increase model
complexity and may reduce model performance.

For Apparel & Textiles applications, feature selection can help identify
the variables that have the strongest relationship with the target
variable.

---

# 2. Why Feature Selection Is Important

Feature selection can help:

- Reduce the number of input variables
- Remove irrelevant information
- Reduce model complexity
- Improve training efficiency
- Reduce overfitting
- Improve interpretability
- Reduce computational requirements
