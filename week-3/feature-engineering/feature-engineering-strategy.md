# Feature Engineering Strategy

## 1. Introduction

Feature engineering is the process of creating useful and meaningful
features from raw data so that Machine Learning models can understand
patterns more effectively.

In the Apparel & Textiles industry, raw datasets may contain information
about products, prices, customers, sales, inventory, seasons and market
trends.

The objective of feature engineering is to convert this raw information
into useful variables that can improve Machine Learning predictions.

---

## 2. Why Feature Engineering Is Important

Good features can help Machine Learning models:

- Improve prediction accuracy
- Identify important patterns
- Reduce unnecessary information
- Improve model training
- Improve interpretability
- Support better business decisions

For example, instead of using only a product's original price, we can
create a discount percentage feature.
